# Android's innocent Malware to implement backdoor for dumping user's data via payload tweaking with apk

- A seemingly innocent Android application (the initial carrier).
- APK payload modification/tweaking, either before installation or during a repackaging process.
- A backdoor component introduced by that payload.
- The backdoor's purpose is data collection and exfiltration from the device.
- The project focuses on understanding or demonstrating this malware technique.
